# US-403 — Alerte sur demandes non traitées

En tant que manager, je veux être alerté des demandes non traitées, afin d'éviter qu'elles soient oubliées.

## Règles
- Une alerte est déclenchée lorsqu'une demande n'a pas changé de statut depuis 5 jours calendaires.
- Une alerte est déclenchée lorsqu'une demande n'a pas changé de statut depuis 3 jours ouvrés.
- Les demandes P1 déclenchent une alerte immédiate.

## Critères d'acceptation
- Une alerte apparaît dans le tableau de bord pour les demandes concernées.
