# US-105 — Champs obligatoires du formulaire

## Besoin
En tant que demandeur,
je souhaite être averti des champs obligatoires manquants avant l'envoi,
afin de ne pas déposer une demande incomplète.

## Règles métier
- RM-01 : titre, description et service sont obligatoires.

## Critères d'acceptation
- Étant donné un formulaire dont le titre est vide, quand je clique sur « Envoyer », alors la demande n'est pas enregistrée et un message indique que le titre est obligatoire.
- Étant donné un formulaire dont la description est vide, quand je clique sur « Envoyer », alors un message indique que la description est obligatoire.
- Étant donné un formulaire dont le service est vide, quand je clique sur « Envoyer », alors un message indique que le service est obligatoire.
- Étant donné un formulaire complet, quand je clique sur « Envoyer », alors la demande est enregistrée au statut « Nouvelle ».

## Dépendances
Aucune.

## Questions ouvertes
Aucune.
