# US-102-c — Importer plusieurs demandes depuis un fichier Excel

## Besoin
En tant que demandeur,
je souhaite importer plusieurs demandes depuis un fichier Excel,
afin de ne pas les saisir une à une.

## Règles métier
- RM-01 : chaque demande importée comporte titre, description et service ; demandeur et date de création sont automatiques.
- RM-08 : chaque demande importée est créée au statut « Nouvelle ».

## Critères d'acceptation
- Étant donné un fichier dont toutes les lignes sont complètes, quand je lance l'import, alors une demande est créée par ligne, au statut « Nouvelle ».
- Étant donné une ligne sans titre, description ou service, quand je lance l'import, alors cette ligne n'est pas importée et le problème lui est associé dans le compte rendu d'import.
- Étant donné un import terminé, quand je consulte le compte rendu, alors il indique le nombre de lignes importées et le nombre de lignes rejetées.

## Dépendances
- US-101, US-105.
- US d'origine : US-102.

## Questions ouvertes
- Format exact du fichier (colonnes, modèle fourni ?) et volume maximal ? Non documenté.
- Une ligne invalide bloque-t-elle tout l'import ou seulement la ligne ? Le critère ci-dessus est une proposition à valider.
- Le service est-il saisi dans le fichier ou déduit du profil ? Non décidé.
