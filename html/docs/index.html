Guides — construire le harness Copilot

Ces fiches accompagnent l'atelier. Elles expliquent comment créer chaque brique de personnalisation de GitHub Copilot dans VS Code, avec des exemples tirés de SprintDesk.

Le parcours#

TempsObjectifGuides
Atelier 1 — PlanifierPoser le contexte du projet dans des instructions claires, puis prompter pour obtenir un plan clair et bien construit01-instructions.md · 02-plan.md

Les briques#

BriqueFichier(s)Chargée quand ?
Instructions.github/copilot-instructions.md, .github/instructions/*.instructions.mdToujours (ou selon les fichiers ciblés)
Agent personnalisé.github/agents/*.agent.mdQuand on sélectionne l'agent
Skill.github/skills/<nom>/SKILL.mdQuand la tâche correspond à sa description
Prompt réutilisable.github/prompts/*.prompt.mdQuand on tape /nom

Quelle brique pour quel besoin ?#

Je veux…J'utilise
Une règle valable pour toutes les conversationsInstructions
Un plan validé avant d'agirMode Plan → PLAN.md
Un rôle avec sa mission, ses outils et ses interditsAgent
Un savoir-faire réutilisable par plusieurs agents (procédure, modèle, checklist)Skill
Lancer une tâche répétitive avec un raccourciPrompt

Règle d'or : ce qui doit toujours être vrai va dans les instructions ; le reste se répartit entre agents (qui ?) et skills (comment ?).

Voir aussi l'aide-mémoire : Aide_Memoire_Participant.pdf.

Les formats évoluent vite. En cas de doute, vérifier la documentation VS Code / GitHub Copilot à jour.
