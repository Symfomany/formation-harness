Ce que l'examen évalue

Le profil visé (audience profile) : opérer, intégrer, superviser et gouverner des agents IA dans un cycle de développement réel, avec GitHub comme système de référence (system of record) et plan de contrôle (control plane).

Sept réflexes qui répondent à une majorité de questions

Quand vous hésitez entre deux réponses, choisissez celle qui :
  1. Impose par un mécanisme plutôt que par une consigne : ruleset, check requis, hook, permission, environnement protégé > phrase dans les instructions.
  2. Donne le moindre privilège : outils listés, jeton en lecture, permissions par job, MCP en lecture seule.
  3. Garde un humain sur l'irréversible (fusion, déploiement, suppression, secrets, droits) et seulement là : une approbation qui ne réduit aucun risque est une mauvaise réponse.
  4. Laisse une trace durable et inspectable : fichier de plan, PR, commit, journal de session, artefact de workflow > « l'agent s'en souviendra ».
  5. Se fonde sur des preuves : résultat CI, scan, journal > affirmation de l'agent (« les tests passent »).
  6. Annule sans réécrire l'histoire : git revert, redéploiement d'un SHA sain > reset --hard, push --force.
  7. Corrige la cause, une chose à la fois : classer (raisonnement, outil, contexte, environnement) avant d'ajuster.
